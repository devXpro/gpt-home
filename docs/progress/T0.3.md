## Decisions
- `Run`/`Status` are methods of `relay.Client` (zero value ready), not package globals.
- `Config.ServerAddr` (dial override) and `Config.SelfCheck` added for harnesses; homed exposes them as
  `--relay-server-addr` and `--relay-ca-file` (test only).
- `CAFile` means "only this CA", matching frp's `trustedCaFile` without `useSystemCa`.
- Spike REST accepts an empty body as `{}`.
- homed listens on loopback only.
