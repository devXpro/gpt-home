## Decisions
- tv_power_on gets `gpt-home/timeout` 60 s (wake waits up to 40 s > hub default 30 s).
- tv_list state: hello ok → on; no hello but ARP entry complete → off; else offline.
- tv_add needs the TV on (model + MAC); default id `tv`, `tv-2`…; default name = friendlyName without "[LG]".
- Names and ids are unique (case-insensitive names) so `tv` can be matched by either.
- Output schemas omitted (Out = any); structuredContent is still returned.
