# T1.2 — Gateway, keys, audit: progress

## Done
- `internal/keys`: `Generate`, `Hash`, `Resolver` (`New([]Entry)`, `Update([]Entry)`, `ResolveKey`), constant-time scan
  over every stored hash. `Entry{Person hub.Person; SHA256 string}` — fed by T1.3 from `homed.yaml`; no YAML here.
- `internal/audit`: `Redact` (recursive, §5.4 regexp), `Open(dir, log)` → `*Log` (`Record` non-blocking via a 1024
  buffer, drops counted in `Dropped()`, `Close()` flushes). Files `<dir>/audit-YYYY-MM.jsonl`, 0600, UTC.
- `internal/gateway`: `New(host, keys, audit, Options) http.Handler` with `/healthz`, `GET /api/v1/tools`,
  `POST /api/v1/tools/{name}`, `/mcp` (stateless go-sdk, JSON responses), `X-GPT-Home-Instance` on every response.
- Tests: auth, scopes, every status row, golden manifest, MCP via go-sdk client, fingerprint, rate limit, audit,
  public Host on loopback. Lint clean on the three packages. Cross-checked once by hand: the librus-gpt Site's
  `mcp.mjs` ran initialize, tools/list and tools/call against the gateway successfully.

## Decisions
- `Options.Instructions` is `func() string` (plugin instructions), re-read on every tool-set change; the hub preamble
  is built from `HomeName`. The frozen `ToolHost` has no instructions accessor, so T1.3 passes one from the host.
- Snapshot is lazy: rebuilt on the first request after `host.Changed()` closes; no goroutine, nothing to close. One MCP
  server and one manifest per scope set (`"*"` or sorted plugin ids).
- The rate limit (token bucket, burst = limit) is per key (sha256) and counts tool calls only, shared by REST and MCP.
- REST check order: 401 → 429 → 404 → 400 → call. Empty body = `{}`. Other host errors → 500 `internal error`.
  Body > 1 MiB → 400. Unknown `/api/...` paths and wrong methods there → JSON 404 (never confused with the relay page).
- MCP failures are `isError` results with text for the model, never JSON-RPC errors.
- `DisableLocalhostProtection: true`: through frpc, requests hit 127.0.0.1 with the public Host and the SDK would 403.
- Audit: every authenticated call attempt is recorded (incl. unknown tool, rate limited, bad body); unauthenticated
  requests are not. Gateway redacts, and the file writer redacts again.
