# gpt-home

A self-hosted bridge between ChatGPT and your home. A small hub (`homed`) runs on a box at home, keeps a single
outbound connection to a cheap relay server, and exposes devices (TV, kettle, ...) to each family member's assistant
through separate plugins.

**Status:** work in progress.

See [docs/PLAN.md](docs/PLAN.md) for the plan and architecture.
